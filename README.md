# NexaPulse Website

A minimal desktop-first multi-page website built with SvelteKit, TypeScript and Vite.

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run check
npm run build
```

## Pages

- `/` — minimal brand homepage: wordmark and bottom tagline.
- `/projects` — separate project directory.
- `/founder` — dedicated founder page. Biography is intentionally not fabricated; replace the placeholder with founder-approved details.
- `/about` — company description.
- `/contact` — contact details.

## Design rules

- Premium restraint: homepage contains only the brand heading and tagline, with navigation kept in the header.
- Burgundy is an accent only, reserved for buttons, active navigation, and selected text/highlights.
- Pale grey/near-white textured background, Urbanist typography, fine borders and generous whitespace.
- Desktop-first layout. No mobile-specific redesign is included.

## Before publishing

Confirm the founder's public name and biography, review project descriptions/statuses, and verify the contact email. The current email is `info@nexapulse.pro`, based on the previously supplied company contact.
